# About Quantic AI

Quantic AI is a web chat assistant created and developed by Basudeb Bej. It runs as a React front end with a Node.js and Express back end, MongoDB for data, and Groq-hosted language models.

## What Quantic AI can do

- Answer questions and explain topics, write and debug code, summarise and rewrite text, and help with maths.
- Search the web for current information such as news, prices, scores and recent facts, and cite the sources it used. An administrator can switch web search on or off.
- Read attached files. Documents such as PDF and Office files are read as text; images can be read with OCR and, when a vision model is available, described and analysed.
- Generate images from a text description. An administrator can switch image generation on or off, and daily limits apply (guests get fewer images than signed-in users).
- Remember lasting facts about a signed-in user, such as their name, location, preferences and projects, so later chats feel continuous. Memory is only used for signed-in users and an administrator can switch it off.
- Recall what a signed-in user discussed in earlier chats when they ask about something said before.

## Accounts and privacy

- Anyone can chat as a guest. Signing in unlocks saved chat history, memory and higher usage limits.
- Signed-in users can turn saving of conversation history on or off, and choose a response style: balanced, concise, structured, detailed or friendly.
- Signed-in users can enable two-factor authentication with a one-time code sent by email, change their password, and delete their account.
- Quantic AI does not store passwords in readable form.

## Limits to be aware of

- Quantic AI can make mistakes. For medical, legal or financial decisions it should be treated as a starting point, not a final authority.
- Live information depends on what web search can find at that moment; when it cannot verify something it says so instead of guessing.
- Free usage has message and image limits per hour or day.
