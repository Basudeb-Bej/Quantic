# Quantic

**AI-powered intelligent chatbot** with RAG, long-term memory, document understanding, and a modern chat interface.

🌐 **Live Demo**: [quantic-nu.vercel.app](https://quantic-nu.vercel.app)



---

## Features

- 🤖 Conversational AI powered by Groq
- 📚 RAG (Retrieval-Augmented Generation) with ChromaDB + local embeddings
- 🧠 Long-term memory system
- 📄 Document intelligence (PDF, Office files, OCR with Tesseract)
- 🔐 Secure authentication (JWT + optional 2FA)
- 🖼️ Image & file upload support
- ⚙️ Admin panel & public announcements
- 🎨 Modern dark UI built with React + Vite

---

## Tech Stack

| Layer       | Technologies                                      |
|-------------|---------------------------------------------------|
| Frontend    | React 19, Vite, TipTap, React Router              |
| Backend     | Node.js, Express 5, MongoDB, Mongoose             |
| AI / RAG    | Groq SDK, ChromaDB, @xenova/transformers          |
| Auth & Sec  | JWT, bcrypt, Speakeasy (2FA), Helmet, Rate Limit  |
| Other       | Nodemailer, Sharp, Tesseract.js, Winston          |
